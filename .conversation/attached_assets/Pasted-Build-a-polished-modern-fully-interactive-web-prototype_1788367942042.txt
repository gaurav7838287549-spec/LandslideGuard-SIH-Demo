Build a polished, modern, fully interactive web prototype called **“LandslideGuard”** for **Smart India Hackathon 2026 Problem Statement SIH26001 — AI-Based Early Warning and Landslide Risk Monitoring System in North Eastern Region (NER)**.

IMPORTANT:
This is an **SIH demo prototype**, not a production emergency system. Use simulated/demo data where real-time APIs or datasets are unavailable. The application must clearly indicate that demo data is simulated.

## 1. TECH STACK

Build a responsive web application using:

* React
* TypeScript
* Tailwind CSS
* Modern component architecture
* Interactive charts
* Interactive GIS-style map
* Lucide icons
* Clean animations and transitions
* Responsive desktop/tablet/mobile design

Use a professional **government + disaster-management + AI dashboard** visual style.

Do NOT make it look like a generic admin dashboard.
